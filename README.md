🌌 NEON SLOPE: Simulation Protocol // v1.0
An Endless, High-Speed Cyberpunk 3D Roll-Runner

NEON SLOPE is an intense, high-velocity 3D rolling endless runner that fuses momentum-based arcade physics with a sleek, late-night synthwave visual aesthetic.

🛸 The Lore
In the year 2088, cyberspace is an endless grid of streaming data highways. You control a Cognitive Core—a glowing cybernetic sphere—navigating the turbulent, collapsing pathways of the mainframe. As the simulation shifts and falls apart beneath you, you must slide, drop, and leap through endless deep-space sectors. Collect isolated Data Units to secure bandwidth, dodge corrupt System Firewalls, and push your core's velocity to its absolute processing limits.

⚡ Key Features
Endless Procedural Pathways: The track generator streams connected platforms ahead of you in real-time. The path bends, narrows, slants sideways, and features launching ramps that shoot you over bottomless void gaps.
System Firewalls & Hazards:
Cognitive Spikes (Red): Pyramids that instantly shatter your core.
Static Firewalls (Red): Solid horizontal blockades obstructing routes.
Sliding Barriers (Pink): Security blocks that oscillate back and forth using smooth sin-wave tracking.
Bandwidth Multiplier System: Snatch floating green Data Nodes to boost your score multiplier (x1.0 up to x2.0, x3.0, and beyond), triggering high-frequency neon HUD alerts.
Generative Web Audio Synthesizer: The game synthesizes its own audio in real-time! It features an adaptive rolling rumble (which pitches up with speed and silences while airborne), steering hums, upward whooshing jump sounds, and a heavy low-pass filtered crash explosion—all set to a continuous retro synthwave bassline.
Hybrid Controls: Zero setup required. Use Keyboard (A/D or arrow keys), Mouse drag, Mobile Touch Zones (virtual left/right pads), or plug in a standard USB Gamepad to steer with the analog joystick!
Customization Settings: Toggle sound effects/music on-the-fly, and switch graphics between Basic, Vibrant, and Hyper profiles to scale Three.js shadow maps and ensure buttery-smooth performance (up to 120 FPS) on any device.
